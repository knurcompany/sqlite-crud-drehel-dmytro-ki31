# Мої книги

Лабораторна робота 6–7 з баз даних. Дрегель Дмитро, група КІ-31.

Додавання, перегляд, редагування та видалення книг. База SQLite створюється під час першого запуску.

Запуск:

```sh
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
python app.py
```

Відкрити http://127.0.0.1:5057/.
